# Hướng dẫn thêm Ảnh và Âm nhạc cho Website

Bạn có thể thay thế các tệp trong thư mục `assets/` này bằng ảnh và nhạc của bạn và Diệu Linh:

1. **Âm nhạc nền**:
   - Đặt bài hát kỷ niệm vào đây và đổi tên thành `music.mp3`.
   - Khi có tệp `music.mp3`, web sẽ tự động phát bài hát này. (Nếu không có, web sẽ dùng âm thanh piano du dương tự tạo sẵn).

2. **Ảnh kỷ niệm**:
   - Thêm 3 bức ảnh của bạn và Diệu Linh vào thư mục này:
     - `photo1.jpg` (Ảnh 1)
     - `photo2.jpg` (Ảnh 2)
     - `photo3.jpg` (Ảnh 3)
   - Nếu chưa có ảnh ngay, trang web sẽ tự động hiển thị ảnh minh họa lãng mạn có sẵn!
